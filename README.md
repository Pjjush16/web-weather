# ️ 极简动态天气 (Minimalist Dynamic Weather)

[**在线演示 (Demo)** | Weather.42Web.io](http://Weather.42Web.io)

一个基于 PHP 和原生 HTML/CSS/JS 开发的轻量级天气查询网页。无需复杂的构建工具，单文件即可运行。

##  功能特点

- ** 实时天气**：基于浏览器定位，自动获取当地实时天气数据。
- ** 动态天气特效**：根据天气状况（晴、雨、雪、雷暴、雾等）和昼夜变化，自动切换动态背景与粒子特效。
- ** 多语言支持**：内置 中文、English、日本語、한국어、Русский 五种语言切换。
- **️ 温度单位切换**：支持摄氏度 (°C) 与华氏度 (°F) 一键切换。
- ** 丰富的数据展示**：包含5天预报、日出日落轨迹图、详细环境指标（气压、湿度、能见度等）及生活指数建议。
- ** 极致轻量**：核心逻辑全部集成在单个 PHP 文件中，部署极其简单。

## ️ 如何运行

由于本项目包含服务器端 PHP 逻辑，**无法直接通过双击 HTML 文件在浏览器中打开**。请按照以下步骤部署：

1.  **准备环境**：确保你有一个支持 PHP 的服务器环境（如 Infinity Free、XAMPP、宝塔面板或任何 Apache/Nginx 服务器）。
2.  **获取 API**：你需要一个天气数据 API 接口（本项目默认支持经纬度传参的 JSON 接口）。
3.  **配置代码**：
    打开 `index.php`，找到第 6 行左右的代码：
    ```php
    $api_url = 'your api website' . $lat . '&lon=' . $lon;
    ```
    将 `'your api website'` 替换为你自己的天气 API 请求地址。
4.  **上传运行**：将修改后的 `index.php` 上传至服务器，通过浏览器访问该文件即可。

##  技术栈

- **后端**：PHP (原生 cURL 请求)
- **前端**：HTML5, CSS3 (GPU 加速动画), Vanilla JavaScript (ES5/ES6)
- **数据**：JSON 格式天气数据

##  开发感想

这是我在学习 Web 开发过程中制作的一个练手项目。虽然代码全部集中在一个文件中，但它涵盖了从后端数据抓取、JSON 解析到前端复杂 DOM 操作与 Canvas 级 CSS 动画的完整流程。

开源这个项目的初衷，是希望记录自己的成长轨迹，同时也为其他初学者提供一个“开箱即用”的参考案例。如果你也喜欢这种极简的动态天气风格，欢迎点个 Star！
